# Michelle Vicente — Editorial Portfolio

A responsive, buildless graphic designer portfolio with forest green, burnt orange, warm cream and butter yellow branding.

## Preview
Open index.html from the downloadable package, or open dist/index.html in the source checkout. No dependencies, installation or build step. Optional local server from this checkout: python3 -m http.server 8000 --directory dist

## Project files
- index.html: page structure and content.
- style.css: responsive editorial design and motion preferences.
- script.js: navigation, project image viewer, category filters, collection search and video coordination.
- portfolio-data.js: selected project details and a metadata index of 32 collections / 575 linked files from the supplied project folder.
- assets/: optimized selected artwork, original MV logo, one black-and-white portrait, and two video reviews.

## Scope of the collection
The full collection browser represents 32 project folders and their inspected subfolders, excluding the certificates collection (linked separately) and previously removed KR Law material. Files can be searched by name, collection or subgroup. The site links to original Drive files; it does not embed or download every file from the archive. The visible selected gallery presents 14 examples across branding, packaging, vehicles, UX/UI, campaigns, apparel, illustration, posters, thumbnails and ecommerce. File counts are file entries, not unique commissioned projects; source collections can contain duplicate formats or versions.

## Personal photo and identity
The black-and-white photo is the only personal portrait, in the About section directly below the opening showcase. The supplied MV logo is retained. Photos are not retouched or generated. ## Validation

## Spacing and effects refinement

Consistent responsive page gutters, section spacing, heading gaps, image frame heights, card text baselines, collection card padding and service row heights. Sticky translucent navigation includes current-section feedback, with a two-pixel scroll-progress line. Work cards use gentle scroll reveals and a subtle pointer-responsive hover glow; buttons and project thumbnails have restrained feedback. Reduced-motion and touch-device rules keep interaction calm. Mobile menu, filtered card reveal, card sizing, dialog opening/closing and horizontal overflow were checked at phone/tablet widths.
